# 社交帖子曝光的影响因素与投放效应测算

全国大学生大数据分析技术技能决赛 · 科目二（本科 Python 组）参赛作品。

以某化妆品品牌 Facebook 主页的 **500 条帖子**为样本，分析发帖决策（帖子类型、内容主题、发布月份/星期/时段、是否付费）对帖子曝光量 `Y1` 的影响，并把回归系数转化为可直接执行的投放建议。项目包含完整的分析代码、结果表、20 张出版级图表与 LaTeX 论文。

## 主要结论

| 问题 | 结论 |
|---|---|
| 核心障碍 | 粉丝规模 `X1` 与发布月份 `X4` 高度同步（Spearman **0.996**，辅助回归 `R²=0.9917`），同时入模导致系数不可识别；按“相关系数 ≥0.9 + 辅助回归 R² ≥0.9 + 月内方差占比 <5%”三项判据剔除 `X1`、保留月份固定效应，最大 VIF 由 **143.0 降至 3.23** |
| 模型表现 | 以 `log(1+Y1)` 为因变量，最终模型 `R²=0.207`、10 折交叉验证 `R²=0.101`、CV RMSE `1.101`（均值基线 `-0.021`）；Breusch–Pagan `p=0.0005`、Jarque–Bera `p<0.001`，推断统一采用 HC3 稳健标准误 |
| 方差来源 | Shapley 分解：帖子类型 **37.1%**、月份 **28.0%**，模型整体可解释 **20.7%**，其余 79.3% 来自未观测的个体差异 |
| 付费效应 | 控制其他变量后，付费帖曝光比自然帖高 **40.1%**（95% CI 10.8%–77.2%），代表性画像上约多 16,142 次曝光 |
| 内容类型 | 视频帖是图片帖的 **4.90 倍**（95% CI 2.23–10.79，但 Video 仅 7 条） |
| 内容主题 | 主题 2、主题 3 分别比主题 1 低 **38.0%**、**27.0%** |
| 稳健性 | 六种模型设定下付费提升 37.4%–49.6%、视频倍数 3.52–5.41，方向与量级一致；付费效应存在主题异质性（组内 `p=0.036`） |

## 数据

- 样本：500 行 × 8 列，帖级截面数据（一行 = 一条帖子，来自同一品牌主页）。
- 输入 `X1`–`X7`，输出 `Y1`（Lifetime Post Total Reach）。
- 原始数据副本：`求解/问题一/临时产物/原始数据副本.csv`。

| 变量 | 含义 | 类型 | 因果角色 | 取值范围 |
|---|---|---|---|---|
| X1 | 粉丝规模（主页粉丝数） | 连续 | 状态/规模 | 81,370–139,441 |
| X2 | 帖子类型 | 名义 | 发帖决策 | Photo / Status / Link / Video |
| X3 | 内容主题 | 名义 | 发帖决策 | 1 / 2 / 3 |
| X4 | 发布月份 | 周期 | 发帖决策（时机） | 1–12 |
| X5 | 发布星期 | 周期 | 发帖决策（时机） | 1–7 |
| X6 | 发布时段（小时） | 周期 | 发帖决策（时机） | 0–23 |
| X7 | 是否付费推广 | 二元 | 发帖决策 | 0 / 1（缺失 1 条，众数填补） |
| Y1 | 曝光总次数 | 计数 | 结果 | 570–1,110,282 |

## 方法路线

```
数据理解（类型/粒度/因果角色/共线量化）
   → 清洗与编码（众数填补、独热编码、log1p/log 变换）
   → 多元线性回归 OLS + HC3
   → 共线性 / 残差 / 整体显著性 / 10 折交叉验证诊断
   → 全模型 vs 去 X1 的月份固定效应模型对比
   → 付费、Video、X3 效应测算与参数模拟置信区间
   → 稳健性检验（Huber、Gamma GLM、不同设定）
```

## 复现

环境（实测）：Python **3.14.3**、pandas 3.0.3、numpy 2.5.1、scipy 1.18.0、statsmodels 0.14.6、scikit-learn 1.9.0、matplotlib 3.11.1、Pillow。

```powershell
pip install numpy pandas scipy statsmodels scikit-learn matplotlib pillow
```

按顺序运行四个主程序（工作目录 `求解/`）：

```powershell
cd 求解
python "问题一\代码\主程序.py"
python "问题二\代码\主程序.py"
python "问题三\代码\主程序.py"
python "问题四\代码\主程序.py"
```

单独重跑某张图（图脚本只依赖 `结果/` 或 `临时产物/` 中的 CSV/JSON）：

```powershell
python "问题三\代码\图8_残差诊断.py"
python "临时产物\验收_总览.py"        # 20 张图拼成验收总览
```

> 说明：`问题一/二` 的主程序通过 `.mrite` 输入登记读取原始 CSV（原始路径为本机 Downloads 目录，登记文件未入库）。在新环境中重跑全流程时，请将 `求解/问题一/临时产物/原始数据副本.csv` 复制到脚本可访问的位置，并相应调整 `_common.py` 中的输入解析；`问题三/四` 直接读取 `求解/清洗数据.csv`，无需原始数据。
