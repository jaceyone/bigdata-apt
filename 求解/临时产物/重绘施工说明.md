## 2. 统一视觉规范（画廊例图的气质，落到这套字体/配色上）

| 项 | 规定 |
|---|---|
| 配色 | 只用上面 `colors` 列表；语义固定：深蓝 `#3C5488`=主/自然/正向，红 `#E64B35`=对比/付费/负向，绿 `#00A087`=第三类，青 `#4DBBD5`=第四类，灰 `#8C8C8C`=不显著/参考 |
| 网格 | 只保留**单向**浅灰网格（`color="#E5E5E5", lw=0.6`），`ax.set_axisbelow(True)` |
| 边框 | 点图/线图/条形图：去掉 top、right；箱线/热图/QQ：四框可留 |
| 刻度 | 向内 `direction="in"`，`length=3`，无次刻度（对数轴次刻度要保留） |
| 字号 | 轴标签 10.5、刻度 9.5、图内注释 8.5–9.5、子图题注 9.5、组名 9 |
| 数值标注 | 关键点/条形末端直接标数值；百分比保留 1 位；p 值 `p<0.001` 写法；CI 用误差棒不用文字堆叠 |
| 图例 | 优先 `top_legend(fig, axes, fontsize=9)` 顶部单行；或图内右上 `frameon=False` |
| 尺寸 | 2×2 → `(11.2, 8.6)`；横向双联 → `(11.8, 5.2)`；纵列双联 → `(8.6, 9.6)`；单面板 → `(7.6, 5.6)` |
| 硬伤（会被打回） | 空面板、平线、中文方块、文字压字、坐标轴被裁切、图例遮挡数据、图注与面板内容不符、dpi<400 |
