# 写作规范（全局 · 机器可读）

## 本次写作参数
- 全篇页数：按内容自然生成。
图片、表格和公式按已完成的求解成果与论证需要引用，数量属于求解约束，不另设写作配额。

本文件为**跨章节**的通用约束与执行指令，随任务注入。每章详细写法见 `论文/` 下对应章节 `.tex` 顶部 `%` 注释（模板自描述），AI 读模板 `.tex` 时自带，无需另找。

## 执行指令
0. 新写内容必须服从本任务明确选择的写作语言及 `.mrite/state/writing-language.json`，优先于模板或旧对话对正文语言的默认约定。选中文就从首稿起用中文写实际题名、摘要、关键词、正文及新生成的图表说明，即使赛事使用英文 CLS 也不能把正文写成英文；选英文则新写内容使用英文。模板自带的章标题、目录标签、封面固定文字和版式可以原样保留，不因正文选中文而强制翻译已有英文章标题。按模板已有接口设置中英文版本，中文默认用 XeLaTeX，英文默认用 PDFLaTeX；中英文兼容报错交由编译入口静默切换引擎，已自动处理的切换不另行提示用户，不改变正文语言，不破坏赛事 CLS 及章节结构。除非用户明确要求翻译，不得自行切换正文语言；外文文献原题、专名、公式、代码、引用键、路径和数值保留真实性。
1. 按章先读后写：进入写论文时 Read `论文.tex` 确认章节顺序；每写一章，只用【工具名为 Read】的工具读取该章节和当前需要的 `\input` 子块。不把所有模板通读作为读题或写作的前置条件；只有相关编译错误才定位 `.cls/.sty`。Bash 的 cat/type/Get-Content、终端输出和提示词预注入内容均不登记读取状态，不能代替 Read。
2. 章节结构以模板为准：顺序 = `论文.tex` 的 `\input` 列表；每层写法 = 该层 `.tex` 顶部 `%` 注释。
3. 只写当前模板实际选用的章节与子块；是否有总体分析、结论或其他模块均由模板决定，不另套固定章节清单。
4. 已存在章节 `.tex` 必须先用 Read 工具读取同一精确路径再 Write/Edit；新建章节/子块文件可直接 Write。
5. 【模型求解放宽】`模型的建立与求解` 的 `subs/` 下按题目实际问题数复制子块（N 问用 `5.1问题1的建立求解`~`5.N问题N的建立求解`）；**其余章节的结构与顺序禁止改动**。
6. 分级递归：任一章节 `.tex` 内 `\input` 的子块也遵守上述规则（先读子块 `.tex` 的 `%` 注释再写）。

## 全局页数与结构
- 数量在求解计划与首次写作时安排，不读取或生成数量核验笔记。
- 全篇页数：按内容自然生成。
  - 篇幅要求在首次写作时安排；编译成功后不再循环压页、补页、删图或改写正文。
- 摘要按当前封面与章节模板规定的篇幅填写，未规定时不额外补设页数限制；摘要内不要出现公式。
- 引言内容与子块按当前模板排列；背景、文献综述、问题描述及本文工作等只写已选用的部分。
- 总体分析是否出现及如何组织，以选中章节的注释为准；模板未选用时不额外添加。
- 模型的建立与求解按实际问题数及选中的子块组织，不添加不存在的问题或未选中的模块。

## 通用约束
- `\title{}` 的「论文标题」占位符必须替换为具体标题，创建时即写。
- 英文论文主标题在最终排版中最多占两行；过长时精简措辞并保持原意，不缩小模板标题字号或挤压版心。
- 正文用自然段落，禁止分点（1.2.3. / ●○ 等）。
- 全篇正文统一单倍行距（公共 `CN.cls` 的 `\baselinestretch=1`）；写作、排版优化和页数调整时均保持单倍，不局部放大或缩小行距。
- 禁止正文加粗（`\textbf` 仅限：摘要「针对问题#」、问题重述「问题N：」、模型假设「假设N：」、模型评价「优点N：/缺点N：」）。
- 所有图表必须被正文引用；标题、坐标轴及图表说明与本任务选择的写作语言一致。
- 不主动添加 `\newpage`；模板已有 `\newpage` 保留。
- 图不画 `set_title()`，标题由 `\caption` 承担。
- tex 只写可编译 LaTeX 代码，不出现提示语。

## 附录代码
- 英文稿附录中的代码注释、说明和读者可见标签也使用英文。本任务新生成且需要在附录展示的 Python 源码不得含中文字符；内部中文路径、文件名等字符串用普通字符串的 `\uXXXX` 转义表示，保持实际路径和运行结果完全相同，不使用会保留反斜杠的 raw 字符串。不要改名实际文件，不改写用户提供的只读源码，也不为排版修改计算结果。
- 按真实代码层级分组：先列项目总主程序（有才列），再按题目实际顺序列问题一、问题二、问题三等。每问优先引用计算入口，再按调用顺序引用理解模型所需的计算模块。同一源码只引用一次，不额外放文件说明表。
- 若项目只有每问的 `求解/问题X/代码/主程序.py`，把它放在对应题目下。若分开存放调度和计算，从已有 `产物清单.json` 的 `calculation.script` 核对实际求解入口，引用该计算源码，按需带上分题入口。旧项目沿用已有路径，不新建总入口或拆分源码。
- 用 Read 核对实际文件，通过 `\lstinputlisting[language=Python]{\detokenize{../求解/问题X/代码/主程序.py}}` 直接引用。路径相对 `论文/`，用 `\detokenize` 保留中文路径及下划线，源码按实际语言标注。不要把源码复制到 `.tex`、改写成示例或另存副本，也不为引用而执行或重跑计算。
- 默认跳过独立的绘图、制表、展示导出、测试和通用运行库代码。若旧脚本混有计算和绘图，按真实行号用 `firstline` 和 `lastline` 只引用计算部分。缺少实际源码时如实说明。

## 图片
- 禁止 `[H]` / `[!h]` 强制定位，统一 `\begin{figure}[ht]`。
- 禁止多图连贴：两图之间必须 1-2 段正文；并排对比用同一 figure 内两张 minipage。
- 版心宽约 16cm；图高+图题 ≤ 16cm。先读 PNG 实宽高再定 `width`，只改 `\includegraphics` 的 width，不动源图。
- 宽高比（高/宽）：`≥0.9` → `0.55~0.65\textwidth`；`0.6~0.9` → `0.60~0.70\textwidth`；`<0.6` → `0.65~0.75\textwidth`；同 figure 并排两张各 `0.45~0.50\textwidth`。

## 表格
- 所有正文表格（表头、数据、说明与续表）及表题统一小五 `\zihao{-5}`（9bp），由公共 `CN.cls` 在表格环境内设置，结束后恢复正文字号；不要用 `\normalsize`、`\small` 或局部字号覆盖它。
- 只允许「符号说明」样式（两列：符号+说明）起步，后可在其基础上增列。
- 只用 `longtable` + `>{\centering\arraybackslash}p{...\textwidth}` 定宽列；禁止 `tabularx`，禁止把 longtable 套进 table 浮动环境。
- 列宽总和 = 1.04 − 0.04×N（2 列 0.96 / 3 列 0.92 / 4 列 0.88 / 5 列 0.84 / 6 列 0.80 / 7 列 0.76 / 8 列 0.72）。
- 列宽经验：数字/公式列 0.09-0.14；中文短词≤5字 0.14-0.18；中文描述 6-12 字 0.18-0.30；长说明 0.36-0.60。数字列收窄。
- 每行 `&` 数量 = 列数 − 1，否则报 `Extra alignment tab has been changed to \cr`。
- 单元格换行：调列宽（总和不变）→ 行列转置 → 精简虚词 + `\tabcolsep` 收至 3pt（表后恢复 6pt）。

## LaTeX 转义（写 .tex 与 bibitem 必须执行）
`&`→`\&`，`%`→`\%`，`#`→`\#`，`_`→`\_`，`^`→`\textasciicircum`，`~`→`\textasciitilde`，`$`→`\$`，`{`→`\{`，`}`→`\}`。
每条 bibitem 写完逐字检查。例：`John Wiley & Sons`→`John Wiley \& Sons`；`50%_off`→`50\%\_off`。

## 编译与结束
在工作区根目录统一运行 `python 论文/编译.py`。入口包含交叉引用所需的编译轮次并更新正式 PDF、SyncTeX 及依赖记录；不要绕过入口。缺包、未定义命令、括号不匹配等致命错误定点修复后再编译；不要输出完整日志，只返回成功状态或错误末尾。
编译成功后立即交付并结束。标准模式不预览全篇、不审图、不检查日志警告、不数页、不进行完成度验收或结果复算，不为页数、字号、图宽或主观美观再次编译。
审核模式仅在宿主明确发起审核后检查图片显示缺陷及空白页、异常大块留白。一次列出明确缺陷并集中修复；只有修改影响 PDF 时才重新编译，不检查模型或结论是否正确，不重复验收全文，不因缺少复核证据而循环。
页数仅在审核模式启用并填写有效范围时由程序读取；达标直接通过，不达标才按宿主安排定点调整。未设置范围不数页、不补页、不压页。未开启图片或排版审核时，不因选择了审核模式就主动检查；生成与最终编译结束后立即交付。
